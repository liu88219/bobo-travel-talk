## ✨ 5 大核心出國實戰功能

1. **🎙️ 雙向面對面對講機（180° 桌面翻轉對話卡）**
   - 支援 **日文 🇯🇵、韓文 🇰🇷、英文 🇺🇸、泰文 🇹🇭、越南文 🇻🇳、法文 🇫🇷、西班牙文 🇪🇸、德文 🇩🇪** 與 **繁體中文 🇹🇼** 雙向即時語音辨識、翻譯與多國語音朗讀（`1.0x 正常` / `0.7x 慢速`）。
   - 上半部外語卡片可 **一鍵 180° 翻轉**，把手機平放桌面就能直接讓對面的店員、飯店櫃檯或計程車司機正著閱讀，並附上**羅馬拼音與台灣人秒懂空耳發音**。
2. **📻 隨身連續收音字幕機（廣播／導覽／店員長篇解說）**
   - 連續收音自動斷句翻譯成「外語原文 ＋ 繁體中文」雙語時間軸卡片，並自動高亮登機門（Gate）、月台（番線）、時間與金額等關鍵字。
3. **📸 拍照菜單翻譯 ＆「店員指指點餐大字卡」**
   - 支援拍照／上傳外文菜單圖片或貼上外文菜名批次免費翻譯＋自動換算台幣價格。
   - 點選份數與飲食忌口（去冰、不要蔥／香菜、不吃牛、小辣、辦理 Tax-Free），一鍵生成**全螢幕地道外語點餐大字卡**並可整單語音朗讀給店員聽。
4. **🪧 100% 離線手指大字卡 ＆ 旅遊空耳句庫**
   - 內建 7 大出國高頻情境句庫（餐廳點餐忌口、購物退稅試穿、問路搭車、飯店入住寄放行李、藥妝買藥症狀、拍照社交、緊急求助）＋自訂行前小卡（飯店地址卡、個人過敏忌口卡），沒網路也能全螢幕秀出並用手機內建離線語音朗讀。
5. **💴 語音標價換算 ＆ 免稅門檻湊單計算機**
   - 念出或輸入外幣標價秒換台幣，並即時顯示距離日本（¥5,500）、韓國（₩15,000）、泰國（฿2,000）、歐洲各國免稅門檻還差多少。
